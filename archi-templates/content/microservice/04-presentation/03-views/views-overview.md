## 概述

本文档描述 {{serviceName}} 表现层的视图分类、视图设计原则、视图与组件/路由的关系，以及主要视图清单。复杂视图可单独建立 `02-<view-name>/01-view-design.md` 并在此处链接。

## 视图分类

- **列表视图**：数据列表、筛选、排序、分页（如订单列表、用户列表）。
- **详情视图**：单条数据展示与编辑（如订单详情、用户档案）。
- **表单视图**：创建/编辑表单、向导。
- **仪表盘/统计视图**：概览、图表、指标卡片。
- **其他**：登录/注册、设置、个人中心等。

## 视图设计原则

1. **与路由一一对应**：每个可访问 URL 对应一个主要视图（或视图容器）；子视图通过路由参数或 Tab 区分。
2. **组件复用**：视图由布局组件（Header、Sidebar、Container）与业务/基础组件组合而成，避免重复实现。
3. **状态边界清晰**：页面级状态（列表数据、当前 Tab）与组件级状态（表单值）分离；跨视图状态通过全局 Store 或 Context 管理。
4. **数据与加载态**：明确数据来源（API、缓存）；统一 Loading、Empty、Error 态与重试策略。

## 视图与组件的关系

- 视图 = 路由 + 布局 + 若干组件 + 状态与副作用。
- 视图不直接依赖具体 API 实现，通过 Port/Adapter 或 Service 层获取数据；组件通过 Props 接收数据与回调。
